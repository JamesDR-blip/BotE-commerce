# PROJECT CONSTITUTION

## Product Identity

AI Studio is evolving into an Autonomous E-commerce Data Operations Platform.

## Architectural Principles

- Evolve existing architecture; do not rewrite without justification.
- Preserve backward compatibility whenever possible.
- Domain layer must remain framework independent.
- Agents must not directly access infrastructure.
- Deterministic logic must use deterministic engines.
- LLM is used only where semantic reasoning is required.

## Safety Principles

- No eval()
- No exec()
- No unsafe YAML
- No arbitrary SQL generated by LLM
- No unrestricted tool execution
- No secret leakage
- No uncontrolled autonomous mutation

## Mutation Principle

Every production mutation must be represented by a ChangeSet.

Every mutation must be:
- traceable
- auditable
- reversible
- risk assessed
- confidence assessed

## Autonomous Operation

High-risk actions require approval unless explicitly permitted by policy.
